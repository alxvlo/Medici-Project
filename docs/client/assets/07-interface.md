## Skip this list if you like

This is the one list you can hand back untouched. If drawing buttons and panels isn't your thing, say so and I will build clean interface in your palette without artwork — it will still look like part of the game. Everything here is optional, and half-finishing it is fine too: send the stars and the level card, skip the dials.

---

## Before you start

**Style.** Match your character sheet: soft cel-shading, dark-brown outlines, muted earthy colours, flat lighting, no heavy gradients.

**Format.** PNG, transparent background. **Draw at twice the size listed** — "240 × 72" means send a 480 × 144 file. Name each file exactly as shown, lowercase, no spaces; a typo means the game shows a grey box instead. **Leave all text off** — I add every word, so buttons and panels should be blank.

The game screen is 960 × 640, landscape.
