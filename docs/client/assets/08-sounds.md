## Before you start

**Format.** MP3 or OGG. Short — under two seconds except the ambience loop. Name each file exactly as shown, lowercase, no spaces.

Sound can be switched off in the game's settings, so nothing here is load-bearing. If you would rather I sourced these, say so and I will.

---

## What these are for

Five sounds. Students will hear the first two hundreds of times across five cases, so both need to be **quiet and unirritating** — a wrong answer already costs a star, and a harsh buzz on top of that just makes the tool unpleasant to practise with.

The exposure sound is the one worth spending effort on. It plays while the student presses and holds the exposure button, and it is the only moment in the game with any weight to it.

## The list

| ✓ | File name | Length | Description |
|---|---|---|---|
| ☐ | `sfx-click.mp3` | < 0.3 s | Soft interface click, for buttons and picking an option. |
| ☐ | `sfx-wrong.mp3` | < 1 s | A gentle low "buzz" for a wrong answer. Not harsh — students will hear this a lot, and it is the *only* thing the console tells them when they set the technique wrong. |
| ☐ | `sfx-correct.mp3` | < 1 s | A soft chime. Plays once, on the review screen as the star rating appears — not during the case. |
| ☐ | `sfx-xray.mp3` | 1.5–2.5 s | **The exposure.** Two parts in one file: a rising rotor hum for about a second as the tube spins up, then the exposure itself — a firm mechanical thunk and a short buzz. The student is holding the button down for the whole of it. |
| ☐ | `ambience-clinic.mp3` | 30–60 s, seamless loop | Quiet clinic background: distant murmur, a soft hum, nothing that draws attention. |

There is no celebration sound. The game ends a case with a review of what the student got right and wrong rather than a fanfare.
