## Before you start

**Style.** Match your character sheet: soft cel-shading, dark-brown outlines, muted earthy colours, flat lighting, no heavy gradients. Backgrounds can be a little more painterly than the characters, but should stay in the same palette.

**Format.** PNG. **These five may be opaque** — they are the only assets that need no transparency. **Draw at twice the size listed:** send 1920 × 1280 files. Name each file exactly as shown, lowercase, no spaces; a typo means the game shows a grey box instead.

The game screen is 960 × 640, landscape, and these fill it edge to edge.

---

## What these are for

Five rooms, one per phase of a case. The student moves through them in this order, and the whole game happens on top of them, so **where you leave empty space matters more than the detail you put in.** Each note below says which part of the frame the game needs kept clear.
